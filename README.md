# 🍽️ Zomato Sales & Business Performance Dashboard

## 📌 Project Overview

This project is an interactive Power BI dashboard developed to analyze Zomato's sales performance, customer behavior, user demographics, and city-level business performance.

The dashboard provides a consolidated view of key business metrics and helps understand sales trends, customer activity, city-wise performance, and user distribution through interactive visualizations.

## 🎯 Project Objectives

- Analyze overall sales and business performance.
- Understand customer demographics and user behavior.
- Identify sales trends across different years.
- Analyze city-wise sales and order performance.
- Monitor user growth, user activity, and customer ratings.
- Generate meaningful insights through interactive visualizations.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Business Intelligence

## 📈 2. Sales Performance Dashboard

The Sales Dashboard focuses on analyzing sales performance and key business metrics.

### Key Analysis
- Total sales performance.
- Overall order and rating metrics.
- Sales trends across different years.
- City-wise sales distribution.
- Sales by food category.
- Comparison of Veg, Non-Veg and other categories.

### Business Purpose

This dashboard helps identify sales trends, understand category contribution, and compare performance across geographical locations.

![Sales Dashboard](Screenshots/Sales_Dashboard.png)

---

## 👥 3. User Performance Dashboard

The User Performance Dashboard focuses on customer activity, demographics, and user-related performance indicators.

### Key Analysis
- User count and active users.
- User ratings and order activity.
- Age-wise user distribution.
- Gender-wise customer analysis.
- Gained and lost users.
- Customer activity and performance trends.

### Business Purpose

This dashboard helps understand customer demographics, user activity, customer retention patterns, and changes in the user base.

![User Performance Dashboard](Screenshots/User_Performance.png)

---

## 🌍 4. City Performance Dashboard

The City Performance Dashboard provides a geographical view of business performance across cities.

### Key Analysis
- City-wise sales performance.
- Order distribution across cities.
- Active users by city.
- City-wise user growth and user loss.
- Comparison of city-level business performance.

### Business Purpose

This dashboard helps compare business performance across cities, identify stronger-performing locations, and understand regional differences in sales and customer activity.

![City Performance Dashboard](Screenshots/City_Performance.png)

This dashboard helps answer the following questions:

- How are overall sales performing?
- Which cities contribute the most to sales?
- How do sales trends change over time?
